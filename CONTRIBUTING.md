# Contributing to SecureAuth

Thank you for contributing to SecureAuth!

SecureAuth is an open-source authentication starter built with Node.js, Express, MongoDB, JWT, email OTP verification, and Vanilla JavaScript.

## Getting Started

### 1. Fork the repository

Fork SecureAuth to your GitHub account.

### 2. Clone your fork

```bash
git clone https://github.com/YOUR_USERNAME/Secure_auth.git
cd Secure_auth
